# pdfAgentNish

## Project name
pdfAgentNish

## Year
2026

## Purpose
AI-powered PDF assistant with hybrid RAG retrieval, reranking, and LLM-based document Q&A.

## Features
- PDF upload and parsing (PyPDF / LangChain loaders)
- Chunking with recursive character text splitting
- Vector storage with Chroma and HuggingFace sentence embeddings
- BM25 ranking support for retrieval
- Chat UI in Streamlit (light/dark theming)
- Groq LLM for answer generation

## Tech Stack used
- Streamlit
- LangChain
- ChromaDB
- Groq
- NumPy
- pypdf
